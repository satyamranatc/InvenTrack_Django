1. Introduction & Abstract

InvenTrack is a full-stack Enterprise Inventory Management and Business Intelligence web application designed to eliminate manual stock tracking errors, automate order-to-stock synchronization, and provide real-time financial and operational visibility. Built using Django 4.2 and Django REST Framework (DRF) on the backend and React.js (Vite) with Tailwind CSS and Recharts on the frontend, the platform unifies product catalog management, category taxonomy, order fulfillment, and an immutable movement audit ledger in one cohesive interface.

Unlike basic CRUD inventory trackers, InvenTrack automatically records every stock change—whether from initial product creation (Inbound), order placement (Outbound), or manual stock correction (Adjustment)—into a tamper-evident InventoryLog ledger. It also monitors batch numbers, expiry dates, warehouse locations, profit margins, and per-SKU low-stock thresholds.

2. Problem Statement & Objectives

Problem Statement

Small and medium-sized warehouses and retail operations frequently rely on spreadsheets or disconnected tools to track stock levels, orders, and supplier batches. This leads to overselling, unrecorded stock shrinkage, missed product expirations, and delayed visibility into profit margins and demand trends.

Key Objectives

  • Provide a secure, JWT-authenticated administrative console for managing categories, products, and customer orders.
  • Automate real-time inventory deduction when orders are created and log every stock delta in an audit trail.
  • Track batch numbers, expiry dates, warehouse shelf locations, cost vs. selling price, and low-stock thresholds.
  • Deliver interactive analytics dashboards including revenue/profit time series, category breakdowns, anomaly detection, and demand forecasting.

4. System Architecture

InvenTrack follows a decoupled client-server architecture. The React frontend communicates with the Django REST API over HTTP using JSON and multipart/form-data (for product images), authenticating requests via Bearer JWT tokens.

7. Core Modules & REST API Endpoints

Endpoint Methods Description
/api/auth/login POST Authenticates via email/username and returns JWT access & refresh tokens
/api/categories GET, POST, PATCH, DELETE Manages global product classifications
/api/products GET, POST, PATCH, DELETE Manages SKUs, pricing, stock, batches, expiry, images, and logs stock changes
/api/orders GET, POST, PATCH, DELETE Manages customer orders, automatically deducting stock on creation
/api/audit-logs GET Read-only chronological movement ledger (Inbound, Outbound, Adjustment)

8. Testing, Verification & Conclusion

The application is verified using Django's APIClient test suite (covering email/username JWT authentication, category/product CRUD, automatic stock deduction on order creation, and audit log generation), ESLint static analysis, and Vite production bundling.

Future Enhancements

  • Role-based access control (Admin, Warehouse Manager, Viewer) and multi-warehouse transfer workflows.
  • Automated email/SMS notifications for low-stock and near-expiry alerts.
  • Barcode/QR scanning and CSV/PDF invoice export.

Conclusion

InvenTrack demonstrates a clean, production-oriented integration of Django REST Framework and React.js, solving real-world inventory accuracy and auditability challenges with automated stock synchronization and rich visual analytics.
